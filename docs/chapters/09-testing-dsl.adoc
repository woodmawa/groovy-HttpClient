[[testing-dsl]]
= Testing DSL (HttpClientTestDsl)

== Overview

`HttpClientTestDsl` is a fluent, embedded HTTP test server specifically designed for testing GroovyHttpClient interactions. Unlike MockHttpServer's validation-focused approach, HttpClientTestDsl provides a flexible, DSL-driven API for defining mock endpoints, recording requests, and verifying interactions.

[quote]
____
Testing HTTP clients should be as expressive as the code you're testing. HttpClientTestDsl makes writing tests feel like writing executable specifications.
____

=== Key Features

* ✅ Embedded HTTP server with automatic port allocation
* ✅ Fluent DSL for defining mock endpoints
* ✅ Request recording and history tracking
* ✅ Rich verification API for assertions
* ✅ JSON and XML response builders
* ✅ Custom response headers and status codes
* ✅ Request matching by method, headers, query params, body
* ✅ Multipart request testing
* ✅ Thread-safe for concurrent tests
* ✅ Spock and JUnit 5 integration

=== When to Use HttpClientTestDsl

[horizontal]
*Complex Tests*:: Multiple endpoints with varied responses
*Request Verification*:: Assert on request headers, body, params
*Dynamic Responses*:: Different responses per call
*Request History*:: Verify call counts, order, content
*Flexible Mocking*:: API-style testing over strict validation

== Quick Start

=== Basic Server Setup

[source,groovy]
----
import org.softwood.http.HttpClientTestDsl
import org.softwood.http.GroovyHttpClient

// Create and start test server
def testDsl = HttpClientTestDsl.create()
testDsl.start()

// Define mock endpoint
testDsl.when("/api/users")
    .respondWith {
        status 200
        json([
            users: [
                [id: 1, name: "Alice"],
                [id: 2, name: "Bob"]
            ]
        ])
    }

// Create client pointing to test server
def client = testDsl.createClient()

// Make request
def response = client.getSync("/api/users")

// Assertions
assert response.statusCode == 200
assert response.json.users.size() == 2
assert response.json.users[0].name == "Alice"

// Verify request was made
testDsl.verify("/api/users") {
    wasCalled(1)
    withMethod("GET")
}

// Cleanup
testDsl.stop()
----

[TIP]
====
Use `testDsl.createClient()` instead of manually constructing a GroovyHttpClient. This automatically configures the client with:

* Correct base URL
* Testing security profile
* Appropriate timeouts
====

=== With Try-With-Resources

For automatic cleanup:

[source,groovy]
----
HttpClientTestDsl.create().withCloseable { testDsl ->
    testDsl.start()
    
    testDsl.when("/data")
        .respondWith {
            status 200
            text "Success"
        }
    
    def client = testDsl.createClient()
    def response = client.getSync("/data")
    
    assert response.statusCode == 200
}
// Automatically stops server
----

== Defining Mock Endpoints

=== Basic Endpoint

[source,groovy]
----
testDsl.when("/api/products")
    .respondWith {
        status 200
        json([
            products: [
                [id: 1, name: "Laptop", price: 999.99],
                [id: 2, name: "Mouse", price: 29.99]
            ]
        ])
    }
----

=== Multiple Endpoints

Define multiple endpoints for different paths:

[source,groovy]
----
// List users
testDsl.when("/api/users")
    .respondWith {
        status 200
        json([users: []])
    }

// Get user by ID
testDsl.when("/api/users/123")
    .respondWith {
        status 200
        json([id: 123, name: "Alice", email: "alice@example.com"])
    }

// Create user
testDsl.when("/api/users")
    .respondWith {
        status 201
        json([id: 456, message: "User created"])
    }

// Delete user
testDsl.when("/api/users/123")
    .respondWith {
        status 204
        body ""
    }
----

[NOTE]
====
The same path can be defined multiple times. Each definition overrides the previous one. This is useful for test-specific setup:

[source,groovy]
----
def setup() {
    testDsl.when("/data").respondWith { status 200; text "default" }
}

def "specific test"() {
    // Override for this test
    testDsl.when("/data").respondWith { status 404; text "not found" }
}
----
====

=== Shorthand Methods

For simple responses:

[source,groovy]
----
// Status only
testDsl.when("/ping").respondWithStatus(200)

// JSON with default 200 status
testDsl.when("/data").respondWithJson([value: 42])

// JSON with custom status
testDsl.when("/error").respondWithJson([error: "Not found"], 404)
----

== Response Configuration

=== Status Codes

[source,groovy]
----
// Success
testDsl.when("/success").respondWith { status 200 }

// Created
testDsl.when("/created").respondWith { status 201 }

// No Content
testDsl.when("/deleted").respondWith { status 204 }

// Not Found
testDsl.when("/missing").respondWith { status 404 }

// Server Error
testDsl.when("/error").respondWith { status 500 }
----

=== Response Bodies

*Plain Text*:
[source,groovy]
----
testDsl.when("/message").respondWith {
    status 200
    text "Hello, World!"
}

// Or using body method
testDsl.when("/data").respondWith {
    status 200
    contentType "text/plain"
    body "Custom content"
}
----

*JSON*:
[source,groovy]
----
testDsl.when("/users/123").respondWith {
    status 200
    json([
        id: 123,
        name: "Alice Smith",
        email: "alice@example.com",
        roles: ["admin", "user"],
        metadata: [
            created: "2025-01-24T10:30:00Z",
            lastLogin: "2025-01-24T15:45:00Z"
        ]
    ])
}
----

*XML*:
[source,groovy]
----
def xmlContent = '''
<user>
    <id>123</id>
    <name>Alice</name>
    <email>alice@example.com</email>
</user>
'''

testDsl.when("/users/123.xml").respondWith {
    status 200
    xml xmlContent
}
----

*HTML*:
[source,groovy]
----
testDsl.when("/page").respondWith {
    status 200
    html """
        <html>
            <head><title>Test Page</title></head>
            <body><h1>Hello!</h1></body>
        </html>
    """
}
----

*Empty Body*:
[source,groovy]
----
testDsl.when("/deleted").respondWith {
    status 204
    body ""
}
----

=== Response Headers

*Single Header*:
[source,groovy]
----
testDsl.when("/data").respondWith {
    status 200
    header "X-Request-ID", UUID.randomUUID().toString()
    json([data: "value"])
}
----

*Multiple Headers*:
[source,groovy]
----
testDsl.when("/api/data").respondWith {
    status 200
    header "Content-Type", "application/json"
    header "Cache-Control", "no-cache"
    header "X-RateLimit-Remaining", "99"
    header "X-RateLimit-Reset", "3600"
    json([data: "value"])
}
----

[IMPORTANT]
====
Headers set via `header` method take precedence over content-type set by helper methods (`json`, `xml`, `text`, `html`).
====

### Custom Content Types

[source,groovy]
----
testDsl.when("/data").respondWith {
    status 200
    contentType "application/vnd.api+json"
    body '{"data":{"type":"articles","id":"1"}}'
}
----

== Request Recording and Verification

=== Basic Verification

[source,groovy]
----
// Make request
client.getSync("/api/users")

// Verify it was called
testDsl.verify("/api/users") {
    wasCalled()  // At least once
}

// Verify call count
testDsl.verify("/api/users") {
    wasCalled(1)  // Exactly once
}

// Verify not called
testDsl.verify("/api/other") {
    wasNotCalled()
}
----

=== Method Verification

[source,groovy]
----
client.postSync("/api/users", null) {
    json([name: "Alice", email: "alice@example.com"])
}

testDsl.verify("/api/users") {
    wasCalled(1)
    withMethod("POST")
}
----

=== Header Verification

*Check Header Exists*:
[source,groovy]
----
client.getSync("/data") {
    header "Authorization", "Bearer token123"
}

testDsl.verify("/data") {
    wasCalled()
    withHeader("Authorization")
}
----

*Check Header Value*:
[source,groovy]
----
testDsl.verify("/data") {
    withHeader("Authorization", "Bearer token123")
}
----

*Multiple Headers*:
[source,groovy]
----
testDsl.verify("/data") {
    withHeader("Authorization", "Bearer token123")
    withHeader("Content-Type", "application/json")
    withHeader("X-Request-ID")
}
----

=== Body Verification

*Exact Match*:
[source,groovy]
----
client.postSync("/submit", "exact body content")

testDsl.verify("/submit") {
    withBody("exact body content")
}
----

*Substring Match*:
[source,groovy]
----
client.postSync("/submit", '{"name":"Alice","age":30}')

testDsl.verify("/submit") {
    withBodyContaining("Alice")
    withBodyContaining('"age":30')
}
----

*JSON Body Matching*:
[source,groovy]
----
client.postSync("/users", null) {
    json([name: "Alice", age: 30, email: "alice@example.com"])
}

testDsl.verify("/users") {
    withJsonBody { json ->
        json.name == "Alice" && json.age == 30
    }
}
----

[TIP]
====
The `withJsonBody` closure receives the parsed JSON and should return `true` for a match. This is more flexible than exact string matching.
====

=== Query Parameter Verification

*Check Parameter Exists*:
[source,groovy]
----
client.getSync("/search") {
    query(q: "groovy", limit: 10)
}

testDsl.verify("/search") {
    withQueryParam("q")
    withQueryParam("limit")
}
----

*Check Parameter Value*:
[source,groovy]
----
testDsl.verify("/search") {
    withQueryParam("q", "groovy")
    withQueryParam("limit", "10")
}
----

=== Accessing Recorded Requests

*Get All Requests*:
[source,groovy]
----
def allRequests = testDsl.recordedRequests
assert allRequests.size() == 3
----

*Get Requests for Path*:
[source,groovy]
----
def userRequests = testDsl.getRequestsFor("/api/users")
assert userRequests.size() == 2
----

*Get First/Last Request*:
[source,groovy]
----
testDsl.verify("/data") {
    wasCalled()
    
    def firstRequest = first()
    assert firstRequest.method == "GET"
    
    def lastRequest = last()
    assert lastRequest.hasHeader("Authorization")
}
----

=== RecordedRequest Properties

[source,groovy]
----
def request = testDsl.getRequestsFor("/data").first()

// Properties
String method = request.method                    // "GET", "POST", etc.
String path = request.path                        // "/data"
Map<String, List<String>> headers = request.headers
String body = request.body
Map<String, List<String>> queryParams = request.queryParams

// Helper methods
String header = request.getHeader("Content-Type")
boolean hasHeader = request.hasHeader("Authorization")
Object json = request.jsonBody
String param = request.getQueryParam("q")
List<String> params = request.getQueryParams("tags")
boolean hasParam = request.hasQueryParam("limit")
----

== Spock Integration

HttpClientTestDsl integrates seamlessly with Spock:

=== Setup/Cleanup Pattern

[source,groovy]
----
import spock.lang.Specification

class UserApiSpec extends Specification {
    
    HttpClientTestDsl testDsl
    GroovyHttpClient client
    
    def setup() {
        testDsl = HttpClientTestDsl.create()
        testDsl.start()
        client = testDsl.createClient()
    }
    
    def cleanup() {
        testDsl.stop()
    }
    
    def "should fetch user by ID"() {
        given: "a mock user endpoint"
        testDsl.when("/users/123").respondWith {
            status 200
            json([id: 123, name: "Alice", email: "alice@example.com"])
        }
        
        when: "fetching user"
        def response = client.getSync("/users/123")
        
        then: "user data is returned"
        response.statusCode == 200
        response.json.id == 123
        response.json.name == "Alice"
        
        and: "request was made"
        testDsl.verify("/users/123") {
            wasCalled(1)
            withMethod("GET")
        }
    }
}
----

=== Shared Server Pattern

For faster tests, share the server across test methods:

[source,groovy]
----
import spock.lang.Shared
import spock.lang.Specification

class UserApiSpec extends Specification {
    
    @Shared HttpClientTestDsl testDsl
    
    def setupSpec() {
        testDsl = HttpClientTestDsl.create()
        testDsl.start()
    }
    
    def cleanupSpec() {
        testDsl.stop()
    }
    
    def cleanup() {
        testDsl.reset()  // Clear endpoints and history between tests
    }
    
    def "test 1"() {
        given:
        testDsl.when("/data").respondWithJson([value: 1])
        // ... test code
    }
    
    def "test 2"() {
        given:
        testDsl.when("/data").respondWithJson([value: 2])
        // ... test code
    }
}
----

=== Complex Verification Example

[source,groovy]
----
def "should create user with proper authentication"() {
    given: "an authenticated endpoint"
    testDsl.when("/users").respondWith {
        status 201
        json([id: 456, message: "User created"])
    }
    
    and: "a client with auth header"
    client.setHeader("Authorization", "Bearer token123")
    
    when: "creating a user"
    def userData = [
        name: "Bob",
        email: "bob@example.com",
        roles: ["user"]
    ]
    def response = client.postSync("/users", null) {
        json(userData)
    }
    
    then: "user is created"
    response.statusCode == 201
    response.json.id == 456
    
    and: "request contains auth header"
    testDsl.verify("/users") {
        wasCalled(1)
        withMethod("POST")
        withHeader("Authorization", "Bearer token123")
        withHeader("Content-Type")
        withJsonBody { json ->
            json.name == "Bob" &&
            json.email == "bob@example.com" &&
            json.roles.contains("user")
        }
    }
}
----

== JUnit 5 Integration

[source,groovy]
----
import org.junit.jupiter.api.*

class UserApiTest {
    
    private HttpClientTestDsl testDsl
    private GroovyHttpClient client
    
    @BeforeEach
    void setup() {
        testDsl = HttpClientTestDsl.create()
        testDsl.start()
        client = testDsl.createClient()
    }
    
    @AfterEach
    void teardown() {
        testDsl.stop()
    }
    
    @Test
    void shouldFetchUser() {
        // given
        testDsl.when("/users/123").respondWith {
            status 200
            json([id: 123, name: "Alice"])
        }
        
        // when
        def response = client.getSync("/users/123")
        
        // then
        Assertions.assertEquals(200, response.statusCode)
        Assertions.assertEquals("Alice", response.json.name)
        
        // verify
        testDsl.verify("/users/123") {
            wasCalled(1)
            withMethod("GET")
        }
    }
    
    @Test
    void shouldHandleNotFound() {
        // given
        testDsl.when("/users/999").respondWith {
            status 404
            json([error: "User not found"])
        }
        
        // when
        def thrown = Assertions.assertThrows(
            GroovyHttpClient.HttpResponseException.class,
            () -> client.getSync("/users/999")
        )
        
        // then
        Assertions.assertEquals(404, thrown.statusCode)
    }
}
----

== Advanced Patterns

=== Testing Async Operations

[source,groovy]
----
def "should handle async requests"() {
    given:
    testDsl.when("/data").respondWithJson([value: 42])
    
    when: "making async request"
    def future = client.get("/data")
    
    and: "waiting for completion"
    def response = future.get()
    
    then:
    response.statusCode == 200
    response.json.value == 42
    
    and:
    testDsl.verify("/data") {
        wasCalled(1)
    }
}
----

=### Multiple Calls to Same Endpoint

[source,groovy]
----
def "should track multiple calls"() {
    given:
    testDsl.when("/counter").respondWith {
        status 200
        json([count: 1])
    }
    
    when: "making multiple requests"
    3.times { client.getSync("/counter") }
    
    then: "all calls are recorded"
    testDsl.verify("/counter") {
        wasCalled(3)
    }
    
    and: "request history is available"
    def requests = testDsl.getRequestsFor("/counter")
    requests.size() == 3
    requests.every { it.method == "GET" }
}
----

=== Testing Request Order

[source,groovy]
----
def "should verify request order"() {
    given:
    testDsl.when("/step1").respondWithStatus(200)
    testDsl.when("/step2").respondWithStatus(200)
    testDsl.when("/step3").respondWithStatus(200)
    
    when:
    client.getSync("/step1")
    client.getSync("/step2")
    client.getSync("/step3")
    
    then:
    def allRequests = testDsl.recordedRequests
    allRequests[0].path == "/step1"
    allRequests[1].path == "/step2"
    allRequests[2].path == "/step3"
}

=== Testing Error Recovery

[source,groovy]
----
def "should retry on server error"() {
    given: "a server that returns 503"
    testDsl.when("/flaky").respondWith {
        status 503
        json([error: "Service unavailable"])
    }
    
    and: "a client with retry policy"
    def retryClient = testDsl.createClient {
        retryPolicy = new RetryPolicy.Config().tap {
            maxAttempts(3)
            on5xx(true)
        }.build()
    }
    
    when: "making a request"
    try {
        retryClient.getSync("/flaky")
    } catch (ignored) {}
    
    then: "multiple attempts were made"
    def requests = testDsl.getRequestsFor("/flaky")
    requests.size() >= 1  // At least one attempt
}
----

=== Testing Multipart Uploads

[source,groovy]
----
def "should upload file via multipart"() {
    given: "a file upload endpoint"
    testDsl.when("/upload").respondWith {
        status 201
        json([uploaded: true, filename: "document.pdf"])
    }
    
    when: "uploading a file"
    def response = client.postMultipartSync("/upload") {
        part {
            name "file"
            filename "document.pdf"
            contentType "application/pdf"
            data pdfBytes
        }
        part {
            name "description"
            content "Important document"
        }
    }
    
    then: "upload succeeds"
    response.statusCode == 201
    response.json.uploaded == true
    
    and: "request was received"
    testDsl.verify("/upload") {
        wasCalled(1)
        withMethod("POST")
        withHeader("Content-Type")  // multipart/form-data
    }
}
----

=== Testing Circuit Breaker Behavior

[source,groovy]
----
def "should open circuit breaker on failures"() {
    given: "a failing endpoint"
    testDsl.when("/failing").respondWith {
        status 503
        text "Service Unavailable"
    }
    
    and: "a client with low circuit breaker threshold"
    def fragileClient = testDsl.createClient {
        failureThreshold = 3
        resetTimeoutMs = 60_000
    }
    
    when: "making requests until circuit opens"
    3.times {
        try { fragileClient.getSync("/failing") } catch (ignored) {}
    }
    
    then: "circuit breaker opens"
    def thrown = null
    try {
        fragileClient.getSync("/failing")
    } catch (GroovyHttpClient.CircuitOpenException e) {
        thrown = e
    }
    thrown != null
    
    and: "requests were attempted"
    testDsl.getRequestsFor("/failing").size() == 3
}
----

== Best Practices

=### Use Descriptive Path Names

[source,groovy]
----
// ✅ Good: Descriptive, intention-revealing
testDsl.when("/users/123").respondWithJson([id: 123, name: "Alice"])
testDsl.when("/orders/search").respondWithJson([results: []])

// ❌ Avoid: Generic, unclear
testDsl.when("/endpoint1").respondWithJson([data: "x"])
testDsl.when("/test").respondWithJson([result: true])
----

=== Reset State Between Tests

[source,groovy]
----
def cleanup() {
    testDsl.reset()  // Clears all endpoints and request history
}
----

=== Use Realistic Response Data

[source,groovy]
----
// ✅ Realistic
testDsl.when("/users/123").respondWith {
    json([
        id: 123,
        name: "Alice Smith",
        email: "alice@example.com",
        created_at: "2024-01-15T10:30:00Z",
        roles: ["user", "admin"],
        metadata: [
            last_login: "2025-01-24T15:45:00Z",
            login_count: 42
        ]
    ])
}

// ❌ Minimal (harder to catch bugs)
testDsl.when("/users/123").respondWithJson([id: 1, name: "A"])
----

=### Verify Request Content

[source,groovy]
----
// ✅ Verify important aspects
testDsl.verify("/users") {
    wasCalled(1)
    withMethod("POST")
    withHeader("Authorization")
    withJsonBody { it.name && it.email }
}

// ❌ Only verify call count
testDsl.verify("/users") {
    wasCalled(1)
}
----

## Limitations

HttpClientTestDsl is designed for straightforward request/response testing:

[horizontal]
*Not Supported*:: WebSocket connections
*Not Supported*:: Server-sent events (SSE)
*Not Supported*:: HTTP/2 server push
*Not Supported*:: Chunked transfer encoding
*Limited*:: Response varies by request content (use conditionals in DSL)

For these scenarios, consider integration testing with real services or specialized tools.

== Troubleshooting

=### Port Already in Use

[source,groovy]
----
// Solution: Let server choose port automatically (default)
def testDsl = HttpClientTestDsl.create()  // Port 0 = auto-assign
testDsl.start()
println "Server on port: ${testDsl.port}"
----

=### Verification Fails

[source,groovy]
----
// Problem: Path mismatch
testDsl.verify("/api/users")  // Fails

// Solution: Check actual recorded paths
def requests = testDsl.recordedRequests
requests.each { println it.path }  // Shows "/users", not "/api/users"
----

=### Headers Not Matching

[source,groovy]
----
// Headers are case-insensitive
testDsl.verify("/data") {
    withHeader("content-type")      // ✅ Works
    withHeader("Content-Type")      // ✅ Works
    withHeader("CONTENT-TYPE")      // ✅ Works
}
----

=### JSON Body Not Matching

[source,groovy]
----
// Problem: Exact string comparison
testDsl.verify("/data") {
    withBody('{"name":"Alice"}')  // May fail due to whitespace/order
}

// Solution: Use JSON matcher
testDsl.verify("/data") {
    withJsonBody { json ->
        json.name == "Alice"
    }
}
----

=### Request History Growing

[source,groovy]
----
// Problem: History accumulates across tests

// Solution: Reset between tests
def cleanup() {
    testDsl.reset()
}

// Or: Check specific requests
def userRequests = testDsl.getRequestsFor("/users")
----

## Performance Tips

[horizontal]
*Shared Server*:: Reuse server across tests (see Spock example)
*Minimal Endpoints*:: Define only needed endpoints per test
*Reset History*:: Clear history between tests to avoid memory growth
*Auto Cleanup*:: Use try-with-resources or cleanup methods
