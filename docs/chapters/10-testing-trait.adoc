[[testing-trait]]
= HttpClientTestTrait

== Overview

`HttpClientTestTrait` is a Groovy trait that seamlessly integrates `HttpClientTestDsl` into Spock specifications. It eliminates boilerplate setup code, provides convenient helper methods, and manages the test server lifecycle automatically.

[quote]
____
Mix in testing superpowers. One trait, zero boilerplate.
____

=== Key Benefits

[horizontal]
*Zero Boilerplate*:: No manual server creation or lifecycle management
*Auto Cleanup*:: Server automatically stopped after tests
*Convenient Helpers*:: Shorthand methods for common operations
*Shared Server*:: Single server instance for all tests (performance)
*Familiar API*:: Exposes `HttpClientTestDsl` methods directly
*Type Safe*:: Full IDE autocomplete and compile-time checking

## Quick Start

=== Basic Usage

[source,groovy]
----
import org.softwood.http.HttpClientTestTrait
import spock.lang.Specification

class UserApiSpec extends Specification implements HttpClientTestTrait {
    
    def "should fetch user by ID"() {
        given: "a mocked user endpoint"
        mockEndpoint("/users/123") {
            status 200
            json([id: 123, name: "Alice"])
        }
        
        when: "fetching user"
        def client = createTestClient()
        def response = client.getSync("/users/123")
        
        then: "user data is returned"
        response.statusCode == 200
        response.json.name == "Alice"
        
        and: "request was made"
        verifyRequest("/users/123").wasCalled()
    }
}
----

That's it! No setup/cleanup, no manual server management.

=== What the Trait Provides

The trait automatically:

* Creates `HttpClientTestDsl` instance
* Starts the test server
* Manages server lifecycle
* Provides helper methods
* Cleans up after tests

## Trait Methods

=== Server Access

*Get Test Server*:
[source,groovy]
----
// Access underlying HttpClientTestDsl
def testServer = this.testServer
println "Server running on: ${testServer.baseUrl}"
----

*Get Base URL*:
[source,groovy]
----
def url = testServerUrl
// e.g., "http://localhost:54321"
----

=== Client Creation

*Create Test Client*:
[source,groovy]
----
// Default testing config
def client = createTestClient()

// With custom config
def client = createTestClient {
    requestTimeout = Duration.ofSeconds(60)
    enableLogging = true
    failureThreshold = 3
}
----

=== Endpoint Mocking

*Simple Endpoint*:
[source,groovy]
----
// Returns MockEndpoint for chaining
def endpoint = mockEndpoint("/api/data")

endpoint.respondWith {
    status 200
    json([data: "value"])
}
----

*With Response Configuration*:
[source,groovy]
----
mockEndpoint("/users") {
    status 200
    json([
        users: [[id: 1], [id: 2]]
    ])
}
----

This is equivalent to:

[source,groovy]
----
testServer.when("/users").respondWith {
    status 200
    json([users: [[id: 1], [id: 2]]])
}
----

## Complete Example

[source,groovy]
----
import org.softwood.http.HttpClientTestTrait
import org.softwood.http.GroovyHttpClient
import spock.lang.Specification

class UserServiceSpec extends Specification implements HttpClientTestTrait {
    
    UserService userService
    
    def setup() {
        def client = createTestClient()
        userService = new UserService(client)
    }
    
    def cleanup() {
        resetTestServer()
    }
    
    def "should list all users"() {
        given: "users endpoint returns list"
        mockEndpoint("/users") {
            status 200
            json([
                users: [
                    [id: 1, name: "Alice", email: "alice@example.com"],
                    [id: 2, name: "Bob", email: "bob@example.com"]
                ],
                total: 2
            ])
        }
        
        when: "fetching users"
        def users = userService.listUsers()
        
        then: "users are returned"
        users.size() == 2
        users[0].name == "Alice"
        users[1].name == "Bob"
        
        and: "correct request was made"
        verifyRequest("/users")
            .wasCalled()
            .withMethod("GET")
    }
    
    def "should get user by ID"() {
        given: "user endpoint returns data"
        mockEndpoint("/users/123") {
            status 200
            json([
                id: 123,
                name: "Alice",
                email: "alice@example.com"
            ])
        }
        
        when: "fetching user"
        def user = userService.getUser(123)
        
        then: "user data is correct"
        user.id == 123
        user.name == "Alice"
        user.email == "alice@example.com"
    }
    
    def "should create new user"() {
        given: "create endpoint returns created user"
        mockEndpoint("/users") {
            status 201
            json([
                id: 456,
                name: "Charlie",
                email: "charlie@example.com"
            ])
            header "Location", "/users/456"
        }
        
        when: "creating user"
        def user = userService.createUser("Charlie", "charlie@example.com")
        
        then: "user is created"
        user.id == 456
        user.name == "Charlie"
        
        and: "correct request was made"
        verifyRequest("/users")
            .wasCalled()
            .withMethod("POST")
            .withHeader("Content-Type", "application/json")
            .withBodyContaining("Charlie")
    }
    
    def "should handle user not found"() {
        given: "endpoint returns 404"
        mockEndpoint("/users/999") {
            status 404
            json([error: "User not found"])
        }
        
        when: "fetching non-existent user"
        userService.getUser(999)
        
        then: "throws exception"
        thrown(UserNotFoundException)
    }
    
    def "should handle server errors"() {
        given: "endpoint returns 500"
        mockEndpoint("/users") {
            status 500
            json([error: "Internal server error"])
        }
        
        when: "fetching users"
        userService.listUsers()
        
        then: "throws exception"
        thrown(ServerException)
        
        and: "request was attempted"
        verifyRequest("/users").wasCalled()
    }
}

// Example service class
class UserService {
    private final GroovyHttpClient client
    
    UserService(GroovyHttpClient client) {
        this.client = client
    }
    
    List<User> listUsers() {
        def response = client.getSync("/users")
        response.json.users.collect { new User(it) }
    }
    
    User getUser(int id) {
        try {
            def response = client.getSync("/users/${id}")
            new User(response.json)
        } catch (HttpResponseException e) {
            if (e.statusCode == 404) {
                throw new UserNotFoundException("User ${id} not found")
            }
            throw e
        }
    }
    
    User createUser(String name, String email) {
        def response = client.postSync("/users", null) {
            json([name: name, email: email])
        }
        new User(response.json)
    }
}

class User {
    int id
    String name
    String email
    
    User(Map data) {
        this.id = data.id as int
        this.name = data.name
        this.email = data.email
    }
}

class UserNotFoundException extends RuntimeException {
    UserNotFoundException(String message) {
        super(message)
    }
}

class ServerException extends RuntimeException {
    ServerException(String message) {
        super(message)
    }
}
----

    and: "both requests were made"

}

== Data-Driven Tests

[source,groovy]
----
def "should handle different status codes"() {
    given: "endpoint returning status"
    mockEndpoint("/api") {
        status statusCode
        body message
    }
    
    when: "making request"
    def client = createTestClient()
    try {
        client.getSync("/api")
        success = true
    } catch (HttpResponseException e) {

    then:
    success == shouldSucceed
    
    where:
    statusCode | message        | shouldSucceed
    200        | "OK"           | true
    201        | "Created"      | true
    204        | ""             | true
    400        | "Bad Request"  | false
    404        | "Not Found"    | false
    500        | "Server Error" | false
}

## Trait Implementation Details

The trait provides:

[source,groovy]
----
trait HttpClientTestTrait {
    @Shared
    private HttpClientTestDsl _testServer
    
    // Lazy initialization
    HttpClientTestDsl getTestServer() {
        if (_testServer == null) {
            _testServer = HttpClientTestDsl.create()
            _testServer.start()
        }
        _testServer
    }
    
    // Convenience methods
    String getTestServerUrl() { testServer.baseUrl }
    
    GroovyHttpClient createTestClient(Closure config = null) {
        testServer.createClient(config)
    }
    
    MockEndpoint mockEndpoint(String path) {
        testServer.when(path)
    }
    
    MockEndpoint mockEndpoint(String path, Closure config) {
        testServer.when(path).respondWith(config)
    }
    
    RequestVerification verifyRequest(String path) {
        testServer.verify(path)
    }
    
    void resetTestServer() {
        testServer.reset()
    }
    
    List<RecordedRequest> getRecordedRequests(String path = null) {
        path ? testServer.getRequestsFor(path) : testServer.recordedRequests
    }
    
    void stopTestServer() {
        _testServer?.stop()
        _testServer = null
    }
}
----

## Comparison: Direct vs Trait

*Without Trait*:
[source,groovy]
----
class ApiSpec extends Specification {
    HttpClientTestDsl testDsl
    GroovyHttpClient client
    
    def setup() {
        testDsl = HttpClientTestDsl.create()
        testDsl.start()
        client = testDsl.createClient()
    }
    
    def cleanup() {
        testDsl.stop()
    }
    
    def "test"() {
        testDsl.when("/api").respondWithStatus(200)
        def response = client.getSync("/api")
        testDsl.verify("/api").wasCalled()
    }
}
----

*With Trait*:
[source,groovy]
----
class ApiSpec extends Specification implements HttpClientTestTrait {
    
    def "test"() {
        mockEndpoint("/api") { status 200 }
        def response = createTestClient().getSync("/api")
        verifyRequest("/api").wasCalled()
    }
}
----

Much cleaner! 🎉

## Limitations

The trait uses a *shared* test server instance:

* Faster (no server restart between tests)
* Must call `resetTestServer()` to avoid test interference
* Port is assigned once and reused

For tests requiring separate servers, use `HttpClientTestDsl` directly.

## Troubleshooting

=== Tests Interfering with Each Other

**Problem**: Test B fails because Test A's mocked endpoints still exist.

**Solution**: Call `resetTestServer()` in `cleanup()`:

[source,groovy]
----
def cleanup() {
    resetTestServer()
}
----

=== "Server not started" Error

**Problem**: Trying to use `testServerUrl` before server is initialized.

**Solution**: Access `testServer` property first to trigger initialization:

[source,groovy]
----
def "test"() {
    given:
    testServer  // Trigger initialization
    def url = testServerUrl  // Now available
}
----

Or just use the helper methods which handle this automatically.

=== Port Conflicts

The trait uses a single shared server for all tests, so port conflicts shouldn't occur. If you need multiple servers, use `HttpClientTestDsl` directly.
