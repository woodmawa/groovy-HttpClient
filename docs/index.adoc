== Preface

A modern, production-ready HTTP client for Groovy 6 and Java 25+, built on the JDK `HttpClient` and virtual threads, with secure defaults, a comprehensive Groovy DSL and a testing framework.

NOTE: Upgrading from 1.x? Read <<upgrading-2>> first -- 2.0.0 changes several security-relevant defaults.

[[api-reference]]
== API Reference

The complete API -- every public class, method and setting -- is in the Groovydoc published with each release (the `-javadoc` artifact on Maven Central), and can be generated locally with `./gradlew groovydoc` (output in `build/docs/groovydoc`). The classes most used directly are `org.softwood.http.GroovyHttpClient` (and its nested `Builder`, `RetryPolicy`, `HttpClientResponse` and exception types), `org.softwood.http.SecurityConfig`, `org.softwood.http.MultipartPart` and `org.softwood.url.URLBuilder`.
